## 결과 해석 (팀이 씁니다)
- 사용한 지표와 수치:피어슨 상관계수($r$): $0.946$ (강한 양의 상관관계)
- 기준선(평균 모델 · 다수 범주 찍기 · 향상도 1 등..)과 비교하면:결정계수($R^2$): $0.895$ (성적 변동의 약 89.5%를 공부 시간으로 설명)
- 이 결과가 뜻하는 것(우리 팀의 해석):설문 조사 결과, 하루 평균 공부 시간이 길어질수록 시험 평균 점수도 함께 높아지는 뚜렷한 양의 상관관계가 확인되었다. 회귀식($\text{점수} = 6.77 \times \text{공부시간} + 63.26$)에 따르면, 하루 공부 시간이 1시간 늘어날 때마다 시험 점수는 평균 약 $6.77\text{점}$ 상승하는 경향을 보인다.
- 우리 팀이 찾아낸 것(인사이트 3개: 헤드라인 → 근거 수치 → 뜻 → 상식과 다른 점):평균 기준 모델 $8.56\text{점}$ → 선형 회귀 모델 $2.62\text{점}$ (오차 약 $69.4\%$ 감소)
  1.공부 시간 증가에 따른 성적 상승 효과 → 상관계수 $r = 0.946$, 회귀 기울기 $+6.77\text{점/시간}$, 1.5시간 이하 구간 평균 $68.8\text{점}$ 대비 3~4.5시간 구간 평균 $91.0\text{점}$으로 $22.2\text{점}$ 상승 → 꾸준한 절대 공부 시간 확보가 성적 향상의 핵심 기반이 된다 → 무조건 오래 앉아 있는 것보다 '1.5시간에서 3시간 사이'로 공부 시간을 늘릴 때 점수 상승 폭이 가장 가파르게 나타났다.
  2.초장시간 학습 구간의 성적 상승 둔화(수확 체감) → 3~4.5시간 구간 평균 $91.0\text{점}$에서 4.5시간 초과 구간 평균 $95.0\text{점}$으로 상승 폭이 $4.0\text{점}$으로 줄어듦 → 일정 시간(약 4시간)을 넘어가면 시간을 추가로 늘려도 점수 상승 효과가 완만해진다 → "무조건 밤새워 공부할수록 성적이 정비례해서 오른다"는 통념과 달리, 일정 수준 이상에서는 집중력과 효율이 중요해진다.
  3.공부 방법에 따른 성적 차이 → 오답노트 정리와 문제집 풀이를 주로 선택한 학생들의 평균 점수가 인강·인터넷 강의 중심 학생들보다 높게 나타남 → 같은 시간을 공부하더라도 스스로 문제를 풀고 틀린 부분을 점검하는 능동적 학습 방식이 성적에 더 유리하다 → 단순히 강의를 오래 듣는 것만으로는 높은 시험 점수로 직결되지 않는다.

## 한계
- 이 결과를 믿을 수 없는 이유(수치로):전체 분석 표본 수가 $18\text{명}$(또는 실제 설문 인원 수)으로 매우 적어 특정 학생 1~2명의 점수 변화에도 상관계수($r = 0.946$)와 기울기가 크게 흔들릴 수 있다. 또한 테스트 데이터 표본이 $4\text{명}$(20%)에 불과해 모델의 오차($\text{MAE} = 2.62\text{점}$)를 전체 학생에게 일반화하기에는 통계적 신뢰도가 부족하다.
- 이 결과를 잘못 쓰면 생길 수 있는 일:상관관계를 인과관계로 오해하여 "수면 시간을 줄여서라도 하루 6시간 이상 공부하면 무조건 100점이 나온다"고 단정 짓는 오류를 범할 수 있다. 또한 공부 시간 외의 요인(선행 학습, 사교육, 수업 집중도, 기초 학력)을 무시한 채 학생의 노력을 공부 시간만으로 평가할 위험이 있다.

- 교과 연계:학생들의 영어 공부 시간(단어 암기, 듣기, 독해, 문제 풀이 등 세부 학습 유형)에 따른 영어 내신·모의고사 성적 변화를 설문으로 조사하고, 학습 전략별 효율성을 분석한 결과를 영어 에세이나 발표 자료로 작성하는 활동으로 확장하고 싶다.
- 진로 분야:미래의 영어 교사로서 단순히 영어 지식만 전달하는 것을 넘어, 학생 개개인의 학습 시간·공부 방법·성취도 데이터를 분석해 맞춤형 피드백을 제공하는 데이터 기반 학습 코칭(AI·에듀테크 활용 영어 교육)을 수업에 적용해 보고 싶다. 특히 공부 시간을 늘려도 성적이 오르지 않아 고민하는 학생들에게 데이터 근거를 바탕으로 효율적인 영어 학습법(오답 분석, 능동적 인출 학습 등)을 안내하는 교사가 되고 싶다.
